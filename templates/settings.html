Discord Email IPv4 change IPv6 change Service problems

Turning off an IP-change alert is handy when one address changes constantly (some ISPs rotate the IPv6 prefix daily) — DNS records are always kept updated either way; these switches only control the messages. If both families change at once, one combined alert goes to every channel enabled for either. Service problems alert once when IP lookup or the Cloudflare API starts failing and once on recovery — never repeated spam.

Scheduled summary

A periodic recap of every IP change in the period — and a proof-of-life signal that the service is still up even when nothing changed. Bi-weekly means every other week on the chosen day; times are the server's local time.

If a summary came due while the service was off, send it right after startup. Turn this off to skip it — the next scheduled summary still covers the whole gap.
